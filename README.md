# فرق را بشنو

One-page sound demo from the «ضرب» study course: the first line of the Shahnameh played at three long-to-short syllable ratios (2, 1.57, 1.3) with the same total length. A fourth button, «تصادفی», gives each long syllable its own ratio, drawn evenly between 1.3 and 2 (rounded to two decimals, shown in the readout, total length unchanged); Each further click on it draws again.

- Live: https://pasmod.github.io/farq-ra-beshno/
- `index.html` is the whole page (no build step). `preview.png` is the X/Open Graph card, rendered from `preview-src.html` with headless Chrome at 1200×630.
