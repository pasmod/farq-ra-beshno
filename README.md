# فرق را بشنو

One-page sound demo from the «ضرب» study course: the first line of the Shahnameh played at three long-to-short syllable ratios (2, 1.57, 1.3) with the same total length.

- Live: https://pasmod.github.io/farq-ra-beshno/
- `index.html` is the whole page (no build step). `preview.png` is the X/Open Graph card, rendered from `preview-src.html` with headless Chrome at 1200×630.
